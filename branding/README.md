# Cinebox branding

This directory contains the original visual identity introduced for the Cinebox fork. The launch artwork uses a dark graphite and burgundy cinema palette, while the application icon is a standalone ruby-red **C** monogram. These assets are original designs and do not reproduce the film-reel emblem or wordmark shown in the user-provided reference.

## Applied resources

| Resource | Source asset | Application target |
| --- | --- | --- |
| Android launch artwork | `generated/cinebox-applaunch-screen.png` | `media/applaunch_screen.png`, `media/splash.jpg`, and `media/banner.png` |
| Cross-platform icons | `generated/cinebox-c-icon.png` | `media/icon*.png` |
| Android launcher icons | `generated/cinebox-c-icon.png` | `tools/android/packaging/media/drawable-*/ic_launcher.png` |

The source artwork is retained here so the asset set can be regenerated for additional packaging targets in future.
